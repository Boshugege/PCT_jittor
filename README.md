# PCT_jittor

A Jittor implementation of Point Cloud Transformer (PCT) for ModelNet40 classification. Created for the PA3 of Computer Graphics 2026 @ Tsinghua University & jittor competition.

#### Usage

```python
python3 pct.py
```

Install jittor via the [instructions from Tsinghua University](https://cg.cs.tsinghua.edu.cn/jittor/download/).

Download dataset and code template at [jittor competition](https://www.educoder.net/competitions/Jittor-7)
